# Prime Number Check Using Function

A simple C program that uses a user-defined function to check whether
a number is prime.

## File

prime_function.c

## Concepts Used

- User-defined function
- Function return value
- for loop
- if-else

## How to Run

gcc prime_function.c -o prime_function
./prime_function

## Sample Output

Enter a number: 17
17 is a prime number
